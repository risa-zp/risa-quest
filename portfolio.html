QUEST 02 / AI-ASSISTED PORTFOLIO

RISA QUEST

好奇心を、人を支える力に。生成AIと対話しながら、RPGの世界観と読みやすさを両立するポートフォリオを制作しています。

制作中生成AIを活用目的・指示・評価・改善

01何を目指したか

採用担当者が、自分の学び・制作・強み・将来像を短時間で理解できることを最優先にしました。冒険マップから自由に選べることと、スクロールで順番に読めることを両立する構成です。

02自分とAIの役割

自分の役割
目的や掲載内容を決めること、デザインの比較、見やすさの評価、改善の指示。
AIの役割
構成・文章・デザイン案の提案、画像生成、コード実装の支援。
使用技術
HTML / CSS / JavaScript
公開方法
GitHub Pages
制作期間

03比較して、伝え直したこと

  1. 複数のコンセプトを比較し、「人を知り、人を支えるための冒険」を選択。
  2. 暗い夜景よりも、明るい昼の景色を選び、文字を大きくするよう指示。
  3. タイトルとマップをトップに統合し、1ページで読める構成へ変更。
  4. 本文の大きなイラストを減らし、文字と情報を主役に整理。
  5. 技術の評価を数値ではなく、経験と次の挑戦のチェックポイントに変更。
  6. ロゴ・空・水・スクロールの演出を検討し、読む邪魔をしない動きを選択。

04冒険マップ

背景イラストはAI生成です。見出しやリンクなどの情報は、画像に埋め込まずWebページの文字として重ねています。
