# RISA QUEST

岸田理沙のインターン応募用ポートフォリオ。

**好奇心を、人を支える力に。**

筑波大学 情報学群 情報科学類・2年。Web制作と情報科学の学びを出発点に、福祉 × 情報 × AIの未来を探しています。

## 構成

- トップ：タイトルと6つの場所をつなぐ冒険マップ
- 同じページに自己紹介・制作物・学習と技術・強み・将来像・次の挑戦
- 制作物だけ別の詳細ページ（life-management.html / portfolio.html。旧calendar.htmlも維持）

技術は実際の学習・使用経験のチェックポイントで表現しています。生成AIを活用して制作しています。

## 技術

HTML / CSS / JavaScript。ビルド不要の静的サイトです。Google Fontsは取得できない場合にシステムフォントへ切り替わります。背景イラストはこのサイト用のAI生成画像です。

## アニメーション

ロゴの中央からの登場、雲の移動、水のきらめき・流れ、初回スクロール時のセクション表示、経験チェック・冒険ルートの演出を実装。停止ボタンとprefers-reduced-motionに対応しています。
