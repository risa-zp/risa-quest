02なぜ作ったか

大学生活をだらだらと過ごしてしまうことがあり、自分の生活にメリハリをつけたいと考えました。予定に加え、目標や振り返りも扱えるアプリを構想しました。

03機能と構想

実装したこと

予定・目標・振り返り

  • カレンダー表示、予定の登録・取得・表示
  • 月間目標・日々の目標の登録・編集
  • 振り返りの登録・編集
未完成・今後の課題

認証・ユーザー管理

ユーザー登録・ログインには取り組みましたが、完成には至っていません。

04技術とデータ

ReactTypeScriptTailwind CSSdaisyUISupabaseGit / GitHub

Supabaseで profiles と schedule などのテーブルを作成しました。予定には、タイトル・開始日時・終了日時・場所・コメント・ユーザーIDなどを保存する形にしました。

フロントエンドに加え、認証、データベース、データの取得・登録、公開まで、Webサービスを作る一連の流れを経験しました。

05開発中の試行錯誤
